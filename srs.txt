# Event Booking System – SRS v1.1

## 1. Project Overview

Event Booking System is a web-based application where users can view available events and book them, while admins can create and manage events and handle booking requests.

The system will provide separate interfaces for users and admins.

---

## 2. Technology Stack

* **Frontend:** React + Vite
* **Styling:** Tailwind CSS
* **HTTP Client:** Axios
* **Backend:** Node.js + Express.js
* **Database:** MongoDB + Mongoose
* **Architecture:** MVC
* **Authentication:** JWT
* **Authorization:** Role-based access
* **Password Security:** bcrypt
* **Email:** Nodemailer with Gmail SMTP

---

* View booking status

* View all their bookings

### Admin

Admins can:

* Create events

`Register → Email OTP → Login → Browse Events → Event Details → Book Event → Booking OTP → Pending → Admin Decision → Payment (if paid) → Confirmed → Dashboard`

## 9. Booking System

The booking process will work as follows:

1. User selects an event.
2. User submits booking details.
3. Booking OTP is sent to the user's email.
4. User verifies the OTP.
5. Booking is created with `Pending` status.
6. Admin reviews the booking.
7. Admin can accept or reject the booking.
8. If accepted:
   * Free event → booking becomes confirmed.
   * Paid event → user can proceed to payment.
9. User can view the booking status from the dashboard.

The system will prevent duplicate bookings for the same event.

The system will also check event availability before creating a booking.

---

## 10. Payment

Payment will be implemented for paid events.

Basic flow:

`Booking Accepted → Pay Now → Payment Gateway → Payment Verification → Booking Confirmed`

The frontend will not directly decide whether a payment was successful. Payment status will be verified by the backend.

Payment integration may be added after the core booking system is completed.
