# Event Booking System

A basic full-stack event booking system where users can browse and book events, while admins can create and manage events and booking requests.

## Tech Stack

### Frontend

* React
* Vite
* Tailwind CSS
* Axios

### Backend

* Node.js
* Express.js
* MVC Architecture

### Database

* MongoDB
* Mongoose

### Authentication

* JWT
* Password Hashing
* Email OTP
* Gmail SMTP

## Main Features

### User

* Register and login
* Email OTP verification
* View events
* Book events
* Booking OTP verification
* View booking status
* Cancel booking
* User dashboard

### Admin

* Admin login
* Dashboard
* Create, edit and delete events
* Manage booking requests
* Accept or reject bookings
* Check paid/unpaid status
* Basic analytics
